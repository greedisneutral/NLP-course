# Неделя 8. Retrieval-Augmented Generation (RAG)

## Дополнительные материалы

- [Vector Institute — RAG Bootcamp](https://github.com/VectorInstitute/retrieval-augmented-generation) — примеры RAG-систем на LangChain и LlamaIndex: загрузка документов, разбиение на фрагменты, эмбеддинги, поиск, переранжирование и оценка качества. Репозиторий содержит ноутбуки для практического изучения разных подходов к RAG.

- [Ragas — How to Evaluate and Improve a RAG App](https://github.com/vibrantlabsai/ragas/blob/main/docs/howtos/applications/evaluate-and-improve-rag.md) — пошаговое руководство по оценке и улучшению RAG: подготовка тестового набора, выбор метрик, запуск экспериментов и анализ ошибок. На примере показано сравнение базового и агентного RAG.

- [Neo4j GraphAcademy — Constructing Knowledge Graphs with Neo4j GraphRAG for Python](https://graphacademy.neo4j.com/courses/genai-graphrag-python) — практический курс по построению графов знаний из текстов и использованию их в GraphRAG. Рассматриваются извлечение сущностей и связей, настройка обработки документов и поиск.
